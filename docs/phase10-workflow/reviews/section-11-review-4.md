## New finding: F9 — `BHV-20` (medium risk) — the first-visit legend does not exist in rendered output

**Criterion:** "The bottom legend bar is first-visit only: it is dismissed
on first interaction, does not return on later visits, and remains
summonable from the Systems Manual."

**What this turn found:** a fresh, unseeded browser context (no
`stock-market-universe-orientation-seen` localStorage key set) never
rendered legend text matching `SUN = WHOLE PORTFOLIO` — not on first visit,
not after an interaction, not after a reload, and not after clicking the
Systems Manual button. Source-level check confirms this is not a timing
issue: no `.tsx` component under `src/components/observatory/orrery/`
references `styles.legend` (the CSS module still defines `.legend` rules in
`orrery.module.css`, but nothing renders them), and `SystemsManual.tsx`
contains no `SUN`/`PORTFOLIO`/legend copy for a summon path to reveal. The
spec's own framing (§5.5) describes this as fixing a *regression* — "the
owner's oldest standing rule is no permanent legends, and the build grew one
back" — but the evidence here is that the legend was removed outright rather
than made first-visit-dismissable-and-summonable. A criterion requiring
dismiss-then-resummon behavior cannot pass against a component that never
renders the content to dismiss or resummon.

**Evidence:** `docs/phase10-baseline/section-11/raw-review-4-audit.json`
(`BHV-20` block: `legendPresentFirstVisit: false`,
`legendPresentAfterInteraction: false`, `legendPresentAfterReload: false`,
`manualButtonVisible: true`, `legendSummonedFromManual: false`), plus a
direct source grep (`.legend` styles orphaned, no TSX reference; no legend
copy in `SystemsManual.tsx`).

**Required change:** implement the first-visit-only legend bar per spec
§5.5 — appears on first visit, dismisses on the first interaction, does not
return on reload, and is re-openable from the Systems Manual — rather than
leaving the CSS in place with no renderer. Do not simply restore a permanent
legend (that recreates the original regression the spec is fixing).
